# PHYSIOGUIDE AI — CERVICAL TRAUMA & RED FLAGS

**Evidence:** Canadian C-spine Rule (Stiell *JAMA* 2001), NEXUS (Hoffman *NEJM* 2000); contraindicaciones Spurling/manipulación; `spine-tests.md`, `clusters-spine.md`

---

## 1. DEFINITION

**Cervical trauma & red flags** = conjunto de presentaciones cervicales que requieren **cribado de seguridad prioritario** antes de cualquier evaluación provocativa o tratamiento manual agresivo: trauma cervical reciente, sospecha de inestabilidad, fractura, lesión ligamentosa, mielopatía, urgencia vascular (disección arterial), infección/meningismo o déficit neurológico progresivo.

No es un módulo de diagnóstico fino. Es un **gate de triaje** que determina: imagen/urgencias vs evaluación MSK segura.

**Regla crítica:** si hay criterios de alto riesgo → **no** Spurling, **no** manipulación thrust, **no** movilizaciones agresivas.

---

## 2. TYPICAL LOCATION / PRESENTATION

| Presentación | Acción orientativa |
|--------------|-------------------|
| Cuello post-trauma (latigazo, caída, deporte) | Canadian C-spine / NEXUS |
| Dolor cervical + brazo + déficit motor progresivo | Mielopatía/radiculopatía severa → médico urgente |
| Cefalea occipital súbita + cuello rígido post-manipulación | Disección arterial → **URGENCIAS** |
| Fiebre + rigidez extrema + fotofobia | Meningismo → **URGENCIAS** |
| Cuello + debilidad piernas / marcha alterada | Mielopatía cervical → urgente |
| Dolor nocturno + pérdida peso + antecedente cáncer | Metástasis/infección screen → médico |

---

## 3. HISTORY (obligatoria en trauma)

- Mecanismo exacto: latigazo, caída altura, cabeza contra objeto, deporte contacto  
- Pérdida de conocimiento  
- Parestesias inmediatas brazo/pierna  
- Déficit motor inmediato o progresivo  
- Anticoagulación / osteoporosis / edad >65  
- Dolor intenso al mínimo movimiento  
- Anestesia en «silla de montar» (también lumbar — cauda)  
- Manipulación cervical reciente (horas/días)  
- Infección reciente, fiebre, inmunosupresión  
- Antecedente cáncer, RA (inestabilidad C1-C2), Down syndrome  
- Pregunta clave trauma: **«¿Puedes mover el cuello sin miedo? ¿Te han dicho que no lo muevas?»**

---

## 4. MECHANISM — TRAUMA GATE

| Mecanismo | Hipótesis de riesgo ↑ |
|-----------|----------------------|
| Latigazo MVC / deporte | Esguince vs fractura vs lesión discoligamentosa |
| Caída >1 m / cabeza primero | Fractura, inestabilidad |
| Impacto directo occipital/cervical | Fractura, lesión vascular |
| Manipulación thrust reciente + cefalea nueva | Disección arterial |
| Trauma menor + anticoagulante | Hematoma epidural (raro pero grave) |
| Trauma repetitivo + dolor creciente | Stress/fractura por estrés (atletas) |

---

## 5. CANADIAN C-SPINE RULE (orientativo)

**Aplicar en trauma** con dolor cervical o mecanismo de latigazo.

**Flujo simplificado:**

```
ALTO RIESGO (≥1):
- Edad ≥65
- Mecanismo peligroso (caída >1m, ejection, bicicleta, buceo, MVC alta energía)
- Parestesias extremidades
→ IMAGEN (no tests provocativos)

SI NO ALTO RIESGO:
- ¿ROM activo (rotación) normal?
  → SI: probablemente no imagen
  → NO: evaluar factores de riesgo intermedios → imagen si ≥1 presente
```

**AI rule:** si no es claramente bajo riesgo → derivar imagen/urgencias. No «tranquilizar» con esguince leve sin cribado.

---

## 6. NEXUS CRITERIA (alternativa)

Imagen indicada si **cualquiera** presente:

- Dolor midline posterior  
- Alteración del estado mental  
- Intoxicación  
- Déficit neurológico focal  
- Distracción dolorosa (otra lesión grave)

**Regla:** NEXUS y Canadian C-spine son herramientas de **cribado**, no diagnóstico de esguince.

---

## 7. MIELOPATÍA CERVICAL — RED FLAG MAYOR

Signos de alarma (cualquiera → **derivación urgente**):

- Torpeza manual (abotonar, escribir, caer objetos)  
- Marcha espástica / inestable / «como borracho»  
- Hiperreflexia, clonus, signo de Babinski  
- Signo de Lhermitte (descarga eléctrica con flexión cervical)  
- Déficit motor progresivo en extremidades  
- Retención urinaria + síntomas cervicales (raro pero grave)

**Regla:** mielopatía ≠ radiculopatía simple. No tratar como «contractura cervical».

---

## 8. URGENCIA VASCULAR — DISECCIÓN ARTERIAL

Sospechar especialmente post-manipulación cervical o trauma menor:

```
CEFALEA SÚBITA DISTINTA (occipital, temporal)
+ DOLOR DE CUELLO
+ SÍNTOMAS NEUROLÓGICOS (mareo, diplopia, disartria, ataxia, Horner)
→ URGENCIAS — NO MANIPULAR — NO SPURLING
```

Otros signos: tinnitus pulsátil, disequilibrio, visión borrosa persistente.

**AI rule:** nunca atribuir a «mareo benigno» sin cribado si contexto post-thrust.

---

## 9. INFECCIÓN / MENINGISMO

| Hallazgo | Acción |
|----------|--------|
| Fiebre + rigidez de cuello extrema | Meningitis/ meningoencefalitis → **URGENCIAS** |
| Fiebre + dolor cervical + inmunosupresión | Absceso epidural / osteomielitis → urgente |
| Post-procedimiento / IV drug use | Infección espinal → urgente |
| Dolor nocturno severo + malestar sistémico | Médico urgente |

**Regla:** no movilización cervical agresiva; derivar.

---

## 10. OTHER RED FLAGS (no trauma)

| Hallazgo | Acción |
|----------|--------|
| Déficit neurológico progresivo | Urgente / neurocirugía |
| Antecedente cáncer + dolor cervical nuevo | Metástasis → médico |
| Dolor nocturno inexplicable + pérdida peso | Médico |
| Inestabilidad atlantoaxial (RA, Down, odontoides) | Imagen antes de manipulación |
| Fractura por estrés (gimnasta, cabeza de portero) | Imagen, no return-to-play |
| Síntomas bilaterales brazos + piernas | Mielopatía / cord → urgente |

---

## 11. EXAMINATION — SAFE APPROACH

**Si red flags activas:**

- Observación postural, nivel de consciencia  
- Inspección (hematoma, deformidad, step-off)  
- **No** Spurling, **no** thrust, **no** end-range repetido  
- Screen neurológico básico (fuerza, reflejos, sensibilidad)  
- ROM solo si Canadian/NEXUS lo permiten y sin dolor intenso

**Si bajo riesgo post-cribado:**

- Transicionar a `cervical-neck-pain.md` para evaluación MSK completa

---

## 12. TESTS CONTRAINDICADOS (alto riesgo)

| Test | Por qué evitar |
|------|----------------|
| Spurling | Cierra foramen; puede empeorar compresión/inestabilidad |
| Manipulación thrust | Riesgo vascular, inestabilidad |
| Tracción cervical agresiva | Inestabilidad, lesión vascular |
| End-range repetido | Puede exacerbar lesión aguda |

**Regla:** contraindicación ≠ «no tocar nunca»; significa evaluación médica/imagen primero.

---

## 13. FUNCTIONAL TESTS (lenguaje paciente — cribado)

- «¿Perdiste el conocimiento en el accidente?»  
- «¿Sientes hormigueo o debilidad en brazos o piernas desde entonces?»  
- «¿Te cuesta abrocharte la camisa o escribir?» (mielopatía)  
- «¿Tuviste una manipulación de cuello y después una cefalea distinta a la habitual?»  
- «¿Tienes fiebre y no puedes mover el cuello?»  
- «¿El dolor empeora cada día en lugar de mejorar?»

Respuestas afirmativas → elevar nivel de urgencia.

---

## 14. IMAGING

| Modalidad | Cuándo |
|-----------|--------|
| **RX cervical (3 vistas)** | Trauma según Canadian C-spine / NEXUS |
| **TC cervical** | Trauma agudo, sospecha fractura, cuando RM no disponible urgente |
| **RM cervical** | Mielopatía, déficit progresivo, sospecha ligamentosa, infección, tumor |
| **Angio-RM / angio-TC** | Sospecha disección arterial |
| **Clinical** | Cribado clínico primero; imagen según reglas, no por defecto |

**Regla:** imagen normal no excluye disección temprana; seguir clínica si sospecha alta.

---

## 15. DIFFERENTIAL (post-cribado bajo riesgo)

| Entidad | Claves |
|---------|--------|
| Whiplash / esguince cervical | Trauma, mecánico, sin red flags, imagen según reglas |
| Latigazo sin fractura | Dolor paracervical, ROM limitado, mejora gradual |
| Radiculopatía post-trauma | Brazo, neural; imagen si persiste/déficit |
| Contusión muscular | Local, sin neurológico |
| Fractura/inestabilidad | Cribado positivo → imagen |
| Mielopatía | Manos/marcha, hiperreflexia → no MSK solo |

---

## 16. COEXISTENCE

- Trauma + radiculopatía preexistente  
- Whiplash + cefalea post-traumática  
- Esguince + ansiedad/postura protectora  

Priorizar **seguridad estructural/vascular** antes de rehabilitación.

---

## 17. DECISION TREE

```
CERVICAL SYMPTOM + ?TRAUMA / RED FLAGS
↓
RED FLAG MAYOR? (mielopatía, meningismo, disección, déficit progresivo)
→ YES → URGENCIAS / HOSPITAL
↓ NO
TRAUMA RECIENTE?
→ YES → CANADIAN C-SPINE / NEXUS
    → NO BAJO RIESGO → IMAGEN / URGENCIAS
    → BAJO RIESGO → NECK PAIN MODULE (MSK)
↓ NO (red flags no traumáticas)
OTHER RF? (cáncer, infección, progresivo)
→ YES → MÉDICO / IMAGEN
↓ NO
→ NECK PAIN MODULE
```

## 18. AI LANGUAGE RULES

**Usar:**

- «Hay criterios que requieren valoración médica/imagen antes de tests provocativos…»  
- «No es seguro realizar Spurling/manipulación en este contexto…»  
- «Compatible con esguince cervical **si** el cribado de trauma es favorable…»  
- «Los signos sugieren posible mielopatía; requiere valoración urgente…»

**Evitar:**

- «Es solo un esguince leve» (sin cribado)  
- «Spurling descartará fractura»  
- «Puedes manipular con confianza» (sin gate)  
- «Mareo post-manipulación es normal» (sin descartar disección)

---

## 19. FINAL CLASSIFICATION

| Clasificación | Criterio |
|---------------|----------|
| **URGENT / EMERGENCY** | Mielopatía, disección, meningismo, déficit progresivo, caída alta energía no cribada |
| **MEDICAL ASSESSMENT** | Canadian/NEXUS positivo, cáncer, infección sospechada, imagen pendiente |
| **PHYSIOTHERAPY (cautela)** | Bajo riesgo confirmado, whiplash sin RF, plan gradual |
| **LOW RISK / INFO** | Solo si cribado completo favorable |
