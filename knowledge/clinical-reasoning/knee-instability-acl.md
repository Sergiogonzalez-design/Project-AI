# PHYSIOGUIDE AI — KNEE INSTABILITY / ACL MODULE (LCA / LCP / ROTATORIA)

**Status:** ACTIVE (rodilla — tras módulo lateral)  
**Next:** Knee master integration  
**Principles:** Mechanism-first; cluster reasoning; no single-test diagnosis

---

## 1. DEFINITION

**Knee instability / ACL-spectrum** = sensación de **fallo, ceder, pop, hinchazón aguda o inestabilidad rotatoria** tras torsión, cambio de dirección o trauma, que puede deberse a **LCA**, **LCP**, **complejo posterolateral (PLC)**, **lesión combinada (tríada)**, **inestabilidad rotuliana**, o **giving-way funcional** (dolor/inhibición sin rotura).

No es un diagnóstico único. El primer filtro es **mecanismo + pop + hinchazón + continuar deporte**, no un test aislado.

---

## 2. TYPICAL PRESENTATION (NO SOLO LOCALIZACIÓN)

La localización del dolor puede ser difusa o secundaria. Priorizar **historia de evento**.

| Presentación | Interpretación orientativa |
|--------------|---------------------------|
| Torsión / corte + pop + hinchazón horas | LCA ↑ |
| No pudo continuar el deporte | LCA / estructural ↑ |
| Cede al girar / cortar | LCA / inestabilidad rotatoria ↑ |
| Golpe en espinilla, rodilla flexionada | LCP ↑ |
| Varo + hiperextensión / contacto | PLC / LCL + LCP |
| «Se sale la rótula» | Inestabilidad rotuliana (otro cluster) |
| Cede por dolor sin pop ni hinchazón | Giving-way funcional / PFPS / menisco |

**Regla:** pop ≠ LCA confirmado. Giving-way ≠ rotura confirmada.

---

## 3. HISTORY

- Mecanismo: no-contacto (pivote) vs contacto  
- **Pop** audible o sentido en el momento  
- ¿Pudo **continuar** el deporte / entrenamiento?  
- Hinchazón: **inmediata / primeras horas** (hemartros) vs tardía  
- Sensación de ceder al girar, cortar, aterrizar  
- Bloqueo (menisco asociado)  
- Lesión previa LCA / reconstrucción  
- **Dolor familiar** en el gesto que reproduce el fallo  

---

## 4. MECHANISM

| Mecanismo | Hipótesis ↑ |
|-----------|-------------|
| No-contacto, deceleración, corte, valgo + rotación | LCA |
| Contacto + valgo | LCA + LCM ± menisco (tríada) |
| Hiperextensión | LCA y/o LCP |
| Golpe anterior tibia (salpicadero, caída de rodillas) | LCP |
| Varo + rotación / hiperextensión | PLC |
| Torsión + bloqueo sin pop claro | Menisco (ver módulos medial/lateral) |

---

## 5. ACL (LCA)

**Patrón compatible (cluster clínico):**

```
TWIST / CUT / NON-CONTACT (o contacto valgo)
+ POP EN EL MOMENTO
+ NO PUDO CONTINUAR
+ HINCHAZÓN EN HORAS (hemartros)
+ GIVING-WAY AL GIRAR
→ ACL COMPATIBILITY ↑
```

**NUNCA:** pop aislado = LCA confirmado.  
**NUNCA:** Lachman positivo aislado = rotura completa confirmada.  
**NUNCA:** cajón anterior en fase aguda dolorosa = diagnóstico (guarda muscular).

Lachman (tope blando) + pivot shift (si tolerable) **apoyan** el cluster; no lo sustituyen.

---

## 6. PCL (LCP)

**Patrón:**

```
GOLPE ANTERIOR TIBIA + RODILLA FLEXIONADA
+/- HINCHAZÓN
+/- SENSACIÓN DE INESTABILIDAD POSTERIOR / BAJADA ESCALERAS
→ PCL COMPATIBILITY ↑
```

Diferencial: LCA (mecanismo distinto), contusión, fractura.

**NUNCA:** cajón posterior aislado en agudo = LCP grado III confirmado.

---

## 7. POSTEROLATERAL CORNER (PLC)

Sospechar si varo, hiperextensión, inestabilidad rotatoria externa, o lesión LCL + LCP.

Cluster: mecanismo varo/hiperextensión + inestabilidad + dolor posterolateral.

Derivar evaluación especializada si inestabilidad rotatoria severa.

---

## 8. COMBINED INJURY (TRÍADA / MULTI-LIGAMENT)

LCA + LCM + menisco medial es frecuente (contacto valgo).

LCA + menisco (medial o lateral) frecuente en no-contacto.

Si inestabilidad en varios planos → no simplificar a «solo LCA».

---

## 9. GIVING-WAY FUNCIONAL vs ESTRUCTURAL

| Patrón | Orientación |
|--------|-------------|
| Pop + hemartros + no continuar + cede al corte | Estructural (LCA) ↑ |
| Cede por dolor anterior, sin pop/hinchazón | PFPS / inhibición cuádriceps |
| Cede + «rótula se sale» | Inestabilidad rotuliana |
| Cede + bloqueo mecánico | Menisco |

---

## 10. DIFFERENTIAL — NOT ACL PRIMARY

- Inestabilidad rotuliana  
- Menisco (bloqueo, línea articular, sin hemartros clásico)  
- LCM/LCL aislado  
- Contusión / esguince grado I  
- Fractura / osteocondral (trauma + no apoyo)  
- LCP (mecanismo salpicadero)  

---

## 11. TEST CLUSTERS

| Cluster | Componentes |
|---------|-------------|
| LCA | Torsión/corte ± no-contacto + pop + no continuar + hinchazón horas + giving-way + Lachman/pivot (si seguro) |
| LCP | Golpe tibia anterior + rodilla flexionada + inestabilidad posterior |
| PLC | Varo/hiperextensión + inestabilidad rotatoria + dolor posterolateral |
| Rotuliana | Episodio de luxación/desplazamiento de rótula |

No inventar Sn/Sp. En fase aguda dolorosa, tests de laxitud pueden ser poco fiables.

---

## 12. COEXISTING PATHOLOGY

LCA + menisco; LCA + LCM; LCP + PLC. Permitir coexistencia; no forzar un único ligamento.

---

## 13. RED FLAGS

- No apoyo post trauma mayor  
- Deformidad / luxación no reducida  
- Bloqueo irreductible  
- Fiebre + hinchazón  
- Déficit neurovascular  
- Inestabilidad multiplanar severa (rodilla luxable) → urgencia  
- Rotura mecanismo extensor (no levanta pierna estirada)  

---

## 14. IMAGING

| Modalidad | Cuándo |
|-----------|--------|
| RX | Fractura, Segond, avulsión, OA |
| RMN | Persistencia, confirmar LCA/LCP/menisco, planificación |
| Eco | Limitada para LCA intraarticular |

Hallazgo RMN de «rotura parcial» ≠ gravedad clínica automática.

---

## 15. AI LANGUAGE

Pruebas funcionales (paciente):

- ¿Te torciste o cambiaste de dirección sin que te golpearan?  
- ¿Sentiste o escuchaste un «pop» o chasquido en el momento?  
- ¿Pudiste seguir jugando o entrenando después?  
- ¿Se hinchó mucho la rodilla en las primeras horas?  
- ¿La rodilla cede o falla al girar o cambiar de dirección?

Lenguaje: «compatible con lesión del ligamento cruzado anterior» — no «rotura completa confirmada» sin cluster + exploración/imagen.

---

## 16. RECOMMENDATION

LOW RISK / physio / medical / urgent según cluster LCA, no apoyo, bloqueo, inestabilidad severa, infección.

Fase aguda: protección, no tests agresivos de pivot si dolor/hinchazón intensa.
