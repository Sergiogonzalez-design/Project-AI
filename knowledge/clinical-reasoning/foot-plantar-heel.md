## 1. DEFINITION

**Dolor plantar / talón plantar / arco medial** = presentación en **inserción medial del calcáneo**, **fascia plantar** o **región plantar**, que puede deberse a **fasciopatía plantar**, **irritación del cojín graso**, **túnel tarsiano**, **stress óseo**, **Aquiles insercional** o **referido S1/lumbar**.

No es un diagnóstico único. «Fascitis plantar» no debe aplicarse automáticamente sin historia típica y cribado de referido neural.

---

## 2. TYPICAL LOCATION

Preguntar siempre:

> «¿Dónde duele exactamente: talón por dentro, centro del talón, arco del pie?»

| Ubicación | Interpretación orientativa |
|-----------|-------------------------|
| Inserción medial calcáneo | Fasciopatía plantar clásica |
| Centro talón (cojín) | Fat pad / contusión |
| Arco medial | Fascia plantar |
| Medial tobillo + ardor | Túnel tarsiano |
| Plantar + pantorrilla + lumbar | S1 referido |
| Metatarsos | Metatarsalgia / neuroma (más distal) |

**Regla:** talón plantar ≠ fascitis automáticamente si SLR/lumbar dominan.

---

## 3. HISTORY (obligatoria)

- **Primeros pasos por la mañana** (muy relevante fasciopatía)  
- Dolor al final del día vs inicio actividad  
- Carga: carrera, bipedestación, peso, superficie  
- Calzado / cambio reciente  
- Trauma directo talón  
- Lumbar / ciática / hormigueo planta o dedos  
- Rigidez arco vs dolor óseo nocturno  
- Deportes (volumen ↑)  
- Pregunta clave: **«¿Duele más al levantarte de la cama?»**

## 5. PLANTAR FASCIOPATHY CLUSTER

**Patrón compatible:**

```
PRIMEROS PASOS POR LA MAÑANA (O TRAS REPOSO)
+ DOLOR INSERCIÓN MEDIAL CALCÁNEO / ARCO
+ PALPACIÓN INSERCIÓN MEDIAL FAMILIAR
± WINDLASS FAMILIAR
+ CARGA (CAMINAR, CORRER, BIPEDESTACIÓN)
→ FASCIOPATÍA PLANTAR COMPATIBILITY ↑
```

**Reglas:**

- Windlass aislado utilidad **limitada** (De Garceau); negativo **no excluye**  
- Historia matutina + palpación pesa más que Windlass solo  
- JOSPT Heel Pain CPG: enfoque multimodal, no diagnóstico por un test

---

## 6. S1 / LUMBAR REFERRAL CLUSTER

**Patrón compatible:**

```
DOLOR PLANTAR O PANTORRILLA
+ LUMBAR / CIÁTICA EN HISTORIA
+ SLR FAMILIAR (O SÍNTOMAS RADICULARES)
+ WINDLASS / PALPACIÓN AQUILES POCO PROVOCATIVOS
± HORMIGUEO PLANTAR
→ REFERIDO S1 / LUMBAR ↑
```

**Regla:** no forzar fascitis si cuadro neural (hormigueo, peor flexión lumbar, SLR positivo).

## 7. LOAD / ACTIVITY PATTERN

Agravantes fasciopatía:

- Primeros pasos  
- Caminar descalzo / sandalias  
- Carrera distancia / velocidad  
- Bipedestación trabajo  
- Subir volumen entrenamiento

Agravantes referido S1:

- Sentado prolongado  
- Flexión lumbar  
- Tos/estornudo (si radicular)  
- SLR en examen

## 8. DIFFERENTIAL

| Entidad | Claves |
|---------|--------|
| Fasciopatía plantar | Mañana, medial calcáneo, carga |
| Fat pad heel | Centro talón, trauma, edad |
| Túnel tarsiano | Ardor, medial tobillo, Tinel |
| Stress calcáneo | Hop dolor óseo, night pain |
| Aquiles insercional | Posterior calcáneo, heel-raise |
| S1 / lumbar | SLR, lumbar, Windlass pobre |
| Neuroma / metatarsalgia | Antepié, no talón |
| DVT | Red flag pantorrilla edema |

## 9. CLINICAL TESTS

### Windlass (dorsiflexión dedos)

- **Purpose:** tensar fascia plantar  
- **Positive:** dolor arco/inserción familiar  
- **AI rule:** apoya fasciopatía en cluster; negativo no descarta

### Palpación inserción medial calcáneo

- **Purpose:** localizar fasciopatía  
- **Positive:** dolor familiar medial  
- **AI rule:** componente clave del cluster

### SLR

- **Purpose:** screen referido lumbar  
- **Positive:** reproduce planta/pantorrilla familiar  
- **AI rule:** sube S1; no cerrar solo fasciopatía

### Hop test

- **Purpose:** carga impacto / stress screen  
- **Positive:** dolor óseo intenso talón  
- **AI rule:** replantear stress fracture; stop si Ottawa+ o no apoya

**Regla:** hop solo si puede apoyar y fractura descartada.

## 11. FUNCTIONAL TESTS

- Caminar primera hora del día  
- Carrera (reproduce?)  
- Bipedestación prolongada  
- Descalzo vs calzado  
- Escaleras

Registrar **familiar pain**.

---

## 12. TEST CLUSTERS

### Cluster A — Fasciopatía

1. Primeros pasos matutinos  
2. Palpación medial calcáneo  
3. Carga agrava  
4. Windlass familiar (opcional)  

→ **Fasciopatía plantar compatibility ↑**

### Cluster B — S1 referido

1. Lumbar/ciática  
2. SLR familiar  
3. Tests locales planta pobres  

→ **Referido S1 compatibility ↑**

**Clasificación:** combinación clínica; no inventar Sn/Sp.

```

```

---

## 14. RED FLAGS

- Edema pantorrilla unilateral + dolor + risk factors → DVT  
- Dolor óseo nocturno + hop intenso → stress fracture  
- Fiebre + inflamación  
- Pérdida neurológica progresiva  
- Trauma mayor + incapacidad apoyar → Ottawa first  
- Dolor plantar agudo severo post-trauma

## 17. AI LANGUAGE RULES

**Usar:**

- «Compatible con fasciopatía plantar…»  
- «Windlass familiar apoya en cluster; negativo no excluye…»  
- «Hay que cribar S1 si SLR reproduce el dolor plantar…»

**Evitar:**

- «Windlass positivo = fascitis confirmada.»  
- «Es plantar fasciitis» sin historia matutina ni palpación  
- Ignorar lumbar si SLR positivo

## 18. FINAL CLASSIFICATION

| Clasificación | Criterio orientativo |
|---------------|---------------------|

| **URGENT** | DVT, fracture, neuro deficit |
