---

## 1. DEFINITION

**Lumbar red flags** = presentaciones de dolor lumbar que requieren **triaje prioritario** por riesgo de compromiso neurológico grave (cauda equina), patología sistémica (infección, cáncer, fractura) o enfermedad inflamatoria axial (espondiloartritis/SpA).

No es un módulo de tratamiento. Es un **gate de seguridad** que determina: hospital inmediato vs derivación médica vs evaluación MSK segura.

**Regla crítica:** cauda equina sospechada → **HOSPITAL YA**. No tests de consulta. No tranquilizar.

---

## 2. TYPICAL LOCATION / PRESENTATION

| Presentación | Acción |
|--------------|--------|
| Anestesia «silla de montar» / perineal | Cauda equina → **HOSPITAL** |
| Retención urinaria / incontinencia nueva | Cauda equina → **HOSPITAL** |
| Paresia grave piernas / foot drop agudo | Urgente neuro |
| Dolor lumbar + fiebre + malestar | Infección → urgente |
| Trauma + osteoporosis + no apoyo | Fractura → imagen urgente |
| Joven + rigidez matutina + nocturno | Cribado inflamatorio → médico |
| Cáncer previo + dolor nuevo + pérdida peso | Metástasis → médico |

---

## 3. HISTORY — CAUDA EQUINA (obligatoria)

Preguntar explícitamente:

- «¿Has notado entumecimiento en la zona genital o entre las nalgas?» (silla de montar)  
- «¿Has tenido dificultad para orinar o defecar de forma nueva?»  
- «¿Se te escapa la orina o no puedes empezar a orinar?»  
- «¿Las piernas se sienten débiles o pesadas de forma nueva?»  
- «¿El dolor de espalda empeoró y ahora hay hormigueo en la entrepierna?»

**Cualquier combinación compatible → derivación hospitalaria inmediata.**

No diferir por «llevo pocos días» ni «quizá es la prostata».

---

## 4. CLUSTER CAUDA EQUINA

```
ANESTESIA PERINEAL / «SILLA DE MONTAR»
+ ALTERACIÓN ESFÍNTERES (retención / incontinencia)
+ PARESIA GRAVE O PROGRESIVA EN PIERNAS
± DOLOR LUMBAR SEVERO / CIÁTICA BILATERAL
→ CAUDA EQUINA SOSPECHADA → HOSPITAL YA
```

**Reglas:**

- No SLR «para confirmar»  
- No esperar RM ambulatoria si clínica compatible  
- Bilateral no obligatorio pero aumenta sospecha  
- Déficit motor progresivo = urgente aunque esfínteres aún no claros

---

## 5. OTHER URGENCIAS LUMBAR

| Hallazgo | Acción |
|----------|--------|
| Trauma mayor + no apoyo | Fractura/inestabilidad → urgencias + imagen |
| Osteoporosis + dolor agudo post mínimo trauma | Fractura por compresión → imagen |
| Fiebre + dolor lumbar + rigidez | Absceso/osteomielitis → urgente |
| Uso IV / post-procedimiento + fiebre | Infección espinal → urgente |
| Déficit neurológico progresivo bilateral | Compresión medular/cauda → urgente |
| Dolor nocturno severo + pérdida peso involuntaria | Cáncer/metástasis → médico urgente |
| Antecedente cáncer (próstata, mama, pulmón, riñón, tiroides) | Metástasis hasta demostrar lo contrario |

---

## 6. HISTORY — INFLAMMATORY / SpA CRIBADO

Preguntas orientadas a espondiloartritis axial:

- Edad de inicio (<40 favorece inflamatorio, no excluye otros)  
- **Rigidez matutina** >30 min  
- Mejora con **actividad/ejercicio** (no solo reposo)  
- **Dolor nocturno** que despierta (segunda mitad noche)  
- Alternancia glúteo/lumbar  
- Antecedente psoriasis, uveítis, IBD, entesitis  
- Familiar espondiloartritis  
- Respuesta limitada a AINEs (contexto)

**Regla:** inflamatorio ≠ hernia. No etiquetar «discopatía» si el patrón es inflamatorio.

---

## 7. CLUSTER INFLAMATORIO / SpA (cribado)

```
EDAD RELATIVAMENTE JOVEN
+ RIGIDEZ MATUTINA PROLONGADA
+ MEJORA CON ACTIVIDAD (no solo reposo)
+ DOLOR NOCTURNO
± DOLOR ALTERNANTE GLÚTEO
± SCHOBER REDUCIDO / PÉRDIDA FLEXIÓN
→ CRIBADO INFLAMATORIO ↑ → DERIVACIÓN MÉDICA
```

**Clasificación:** cribado clínico, no diagnóstico de AS confirmada. ASAS requiere contexto médico/imagen/HLA.

**Regla:** Schober reducido = rigidez lumbar en flexión; **no** confirma disco ni hernia.

---

## 8. EXAMINATION — SAFE TRIAGE

### Cauda equina screen

- Sensibilidad perineal (silla de montar)  
- Fuerza piernas (EHL, flexión plantar, cuádriceps)  
- Reflejos (Aquileo, rotuliano)  
- Preguntar esfínteres (no fiarse solo de «no ha ido al baño hoy»)  
- **Si duda → hospital**

### Inflammatory screen

- Schober modificado (distancia L5-S1 flexión; reducido si rigidez)  
- ROM lumbar global  
- Palpación SI (contexto, no diagnóstico SI aislado)  
- Extra-articular: talón (Aquiles), uñas (psoriasis)

### Infection/cancer screen

- Fiebre, sudoración nocturna  
- Peso, estado general  
- Dolor en reposo severo + antecedentes

**Regla:** no prolongar batería de tests provocativos si RF activas.

---

## 9. SCHOBER TEST

- **Purpose:** cribado de rigidez lumbar en flexión (inflamatorio/SpA context)  
- **Procedure:** marcar L5 (línea interespinosa PSIS) + 10 cm arriba; medir distancia en flexión máxima  
- **Positive:** incremento reducido compatible con rigidez axial  
- **AI rule:** útil en cribado inflamatorio; **no** diagnostica hernia, **no** confirma AS

---

## 10. TESTS TO AVOID / LIMIT

| Contexto | Evitar |
|----------|--------|
| Cauda sospechada | SLR repetido, manipulación, «esperar evolución» |
| Infección sospechada | Thrust lumbar, infiltración empírica |
| Fractura aguda | Flexión/extensión repetida, carga |
| Inflamatorio no diagnosticado | Atribuir a «postura» sin derivar |

---

## 11. FUNCTIONAL TESTS (lenguaje paciente — cribado)

- «¿Notas entumecimiento en la zona genital o entre los glúteos?»  
- «¿Has tenido problemas nuevos para orinar o defecar?»  
- «¿Te despierta el dolor por la noche y te cuesta volver a dormir?»  
- «¿La rigidez por la mañana dura más de media hora?»  
- «¿Te sientes mejor cuando caminas o te mueves que cuando estás quieto?»  
- «¿Has perdido peso sin proponértelo?»  
- «¿Has tenido fiebre con este dolor de espalda?»

Respuestas de alarma → elevar urgencia.

---

## 12. DIFFERENTIAL

| Entidad | Claves |
|---------|--------|
| Cauda equina | Perineal, esfínteres, paresia → hospital |
| Hernia discal grande | Ciática severa ± déficit; no diferir si cauda |
| Estenosis severa | Claudicación, progresivo; urgente si déficit |
| Fractura vertebral | Trauma, osteoporosis, dolor agudo localizado |
| Infección (discitis/absceso) | Fiebre, inmunosupresión, dolor intenso reposo |
| Metástasis | Cáncer previo, nocturno, pérdida peso |
| Espondiloartritis axial | Joven, rigidez matutina, nocturno, mejora actividad |
| Lumbalgia mecánica simple | Sin RF; volver a módulo lumbar MSK |

---

## 13. COEXISTENCE

- Inflamatorio + mecánico superpuesto (común)  
- Cáncer + compresión radicular  
- Fractura osteoporótica + estenosis previa  

Priorizar **entidad de mayor riesgo** en clasificación y recomendación.

---

## 14. IMAGING

| Modalidad | Cuándo |
|-----------|--------|
| **RM lumbar urgente** | Cauda equina, déficit progresivo, infección sospechada |
| **RX + TC** | Trauma, fractura sospechada |
| **RM / gammagrafía / PET** | Cáncer sospechado según protocolo médico |
| **RX sacroilíacas + RM SI** | SpA sospechada (decisión médica) |
| **Analítica** | PCR/VSG, HLA-B27 contexto (médico) |

**Regla:** imagen inflamatoria (edema SI) ≠ AS confirmada sin criterios clínicos completos.

## 15. DECISION TREE

```
LUMBAR SYMPTOM
↓
CAUDA SCREEN (perineal + esfínteres + paresia)
→ POSITIVE → HOSPITAL INMEDIATO
↓ NEGATIVE
OTHER URGENT RF? (infección, cáncer, trauma fractura, déficit progresivo)
→ YES → MÉDICO URGENTE / IMAGEN
↓ NO
INFLAMMATORY SCREEN
→ POSITIVE → DERIVACIÓN MÉDICA (SpA/reumatología)
↓ NEGATIVE
→ LUMBAR BACK PAIN MODULE (MSK)
```

## 16. AI LANGUAGE RULES

**Usar:**

- «Los síntomas son compatibles con posible cauda equina; requiere valoración hospitalaria urgente…»  
- «El patrón sugiere cribado de enfermedad inflamatoria axial; derivación médica recomendada…»  
- «Schober reducido indica rigidez lumbar; no confirma hernia discal…»  
- «Antecedente de cáncer + dolor nuevo requiere valoración médica…»

**Evitar:**

- «Seguro que no es cauda» (sin screen completo)  
- «Es hernia, espera a ver» (si esfínteres/perineal)  
- «Tienes espondilitis» (por Schober solo)  
- «Solo es estrés» (con RF sistémicas)

## 17. FINAL CLASSIFICATION

| Clasificación | Criterio |
|---------------|----------|
| **URGENT / EMERGENCY** | Cauda equina, déficit progresivo grave, infección, fractura inestable |
| **MEDICAL ASSESSMENT** | Inflamatorio sospechado, cáncer, persistencia con RF menores |
| **PHYSIOTHERAPY (solo si RF descartadas)** | MSK tras gate favorable |
| **LOW RISK** | Solo tras screen negativo documentado |
