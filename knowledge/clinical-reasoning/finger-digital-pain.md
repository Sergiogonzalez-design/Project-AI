## 1. DEFINITION

**Finger / digital pain** = síntomas localizados en uno o varios **dedos** (incluido pulgar), que pueden ser **neurales** (parestesias de origen mediano/cervical — típico STC), **mecánicos locales** (A1/trigger, esguince interfalángico, UCL pulgar) o **tendinosos/traumáticos** (jersey finger, mallet).

No es un diagnóstico único. Es una **presentación** que exige localización exacta, mecanismo, **dolor familiar** y enrutado neural vs local.

**Regla maestra:** Phalen/Tinel **apoyan** STC en cluster; **nunca** confirman STC aislados.

---

## 2. TYPICAL LOCATION

Preguntar siempre:

> «Señala con un dedo dónde te duele o hormiguea.»

| Ubicación | Interpretación orientativa |
|-----------|-------------------------|
| Pulgar, índice, medio (± mitad radial anular) + hormigueo | STC / mediano (cluster) |
| Solo meñique / borde cubital | Cubital — no STC; ver módulo neural codo/muñeca |
| Nudillo palmar (A1) + chasquido/bloqueo | Trigger finger / tenosinovitis A1 |
| IFP / punta del dedo + trauma flexión | Jersey finger (FDP) — sospecha |
| IFD / uña + no extiende punta | Mallet (extensor IFD) |
| MCP pulgar + valgo/ESGRIMA | UCL pulgar (gamekeeper/skier) |
| IF proximal/distal + torsión | Esguince interfalángico |

**Regla:** un dedo bloqueado ≠ STC automáticamente.

---

## 3. HISTORY (obligatoria)

- Dedo(s) afectado(s), mano dominante, deporte (baloncesto, escalada, artes marciales)  
- Inicio: agudo vs insidioso  
- Mecanismo: caída, balón, torsión, agarre, repetitivo, sin causa  
- **Dolor familiar:** «¿Es el mismo dolor/hormigueo que notas al usar la mano?»  
- Bloqueo, chasquido, rigidez matutina  
- Hormigueo nocturno, sacudir la mano (STC)  
- Deformidad, hinchazón, herida  
- Flexión/extensión completa posible  
- Lesión previa del mismo dedo  
- Síntomas de cuello si hay parestesias atípicas

---

## 4. NEURAL GATE — STC vs LOCAL

Antes de patología digital local, cribar si domina **neuropatía mediana**:

```
PARESTESIAS NOCTURNAS TERRITORIO MEDIANO (1.º–3.º ± mitad radial anular)
± SACUDIR LA MANO
± PHALEN ± TINEL (apoyan, NO confirman)
± DIAGRAMA KATZ / AGARRE EMPEORA
→ STC COMPATIBILITY ↑
```

**Reglas críticas:**

- Phalen/Tinel **negativos no descartan** STC  
- Phalen/Tinel **positivos no confirman** STC  
- Meñique solo → **cubital**, no STC  
- Cuello + territorio atípico → cervical ↑ (ver `elbow-wrist-neural.md`, `cervical-neck-pain.md`)  
- Déficit abducción pulgar = más grave → valoración médica

## 5. TRIGGER FINGER / TENOSINOVITIS A1

**Typical:** dolor palmar en **nudillo** (A1), chasquido o bloqueo al flexionar, a veces desbloqueo con el otro dedo, empeora con agarre/repetitivo.

**Patrón compatible:**

```
DOLOR PALMAR NUDILLO (A1)
+ CHASQUIDO O BLOQUEO EN FLEXIÓN FAMILIAR
+ RIGIDEZ MATUTINA O TRAS ACTIVIDAD
± PALPACIÓN A1 DOLOROSA
→ TRIGGER / A1 COMPATIBILITY ↑
```

**Diferencial:** artrosis IF, esguince, STC (si hormigueo domina).

**Limitación:** bloqueo ocasional inespecífico; cluster con palpación + historia.

---

## 6. JERSEY FINGER (ruptura FDP)

**Typical:** trauma en **flexión forzada** (agarre de camiseta, balón, escalada); dolor IFP; **incapacidad activa de flexionar la IFP** (no solo dolor).

**Patrón:**

```
TRAUMA EN FLEXIÓN (deporte / agarre)
+ INCAPACIDAD FLEXIÓN ACTIVA IFP
± HEMATOMA / HINCHAZÓN IFP
→ JERSEY FINGER SOSPECHA ↑ → VALORACIÓN MÉDICA / IMAGEN
```

**Regla:** flexión pasiva posible con FDP roto; test de flexión activa IFP aislada es clave.

**No confundir con:** esguince IF leve (flexión activa conservada).

---

## 7. MALLET FINGER (extensor IFD)

**Typical:** golpe en **punta del dedo** (balón, puerta); IFD en **flexión**; no puede mantener extensión activa de la IFD.

**Patrón:**

```
TRAUMA EN PUNTA / IFD FLEXIONADA
+ INCAPACIDAD EXTENSIÓN ACTIVA IFD
± DEFORMIDAD EN «MARTILLO»
→ MALLET COMPATIBILITY ↑
```

**Regla:** extensión pasiva puede ser normal al inicio; déficit **activo** IFD.

**Red flag:** fractura avulsión asociada → imagen.

---

## 8. UCL PULGAR (gamekeeper / skier's thumb)

**Typical:** valgo forzado del pulgar (esquí, balón, caída); dolor **MCP pulgar**; inestabilidad al estrés en valgo; pinza débil.

**Patrón:**

```
TRAUMA EN VALGO PULGAR
+ DOLOR MCP PULGAR FAMILIAR
+ INESTABILIDAD / DOLOR EN ESTRÉS UCL (valgo)
± HEMATOMA / HINCHAZÓN MCP
→ UCL PULGAR COMPATIBILITY ↑
```

**Diferencial:** contusión MCP, fracture Bennett/Rolando, De Quervain (sin trauma valgo).

**Regla:** UCL positivo ≠ rotura confirmada sin imagen/clínica integrada.

---

## 9. ESGUINCE INTERFALÁNGICO (IF)

**Typical:** torsión o hiperextensión; dolor articular IF; hinchazón local; ROM limitado pero **sin** patrón FDP/mallet/UCL.

**Patrón:**

```
TRAUMA TORSIONAL / HIperextensión IF
+ DOLOR ARTICULAR LOCAL FAMILIAR
+ FLEXIÓN Y EXTENSIÓN ACTIVAS CONSERVADAS (sin bloqueo A1 dominante)
± INESTABILIDAD LATERAL IF
→ ESGUINCE IF COMPATIBILITY ↑
```

**Diferencial:** mallet (extensión IFD), jersey (flexión IFP), trigger (nudillo palmar).

---

## 10. PALPATION

| Zona | Qué buscar |
|------|------------|
| A1 (nudillo palmar) | Tenderness + chasquido |
| IFP / IFD | Dolor articular post-trauma |
| MCP pulgar | UCL, hematoma |
| Pliegue muñeca | Tinel mediano (si neural) |

**Familiar pain** en palpación aumenta peso clínico.

|---------|-------------------|

| **IF sprain** | Trauma IF + dolor local sin déficit FDP/mallet |

**Clasificación:** combinación clínica; no inventar Sn/Sp ni scores.

## 12. DECISION TREE

```
DEDO / DEDOS — DOLOR O PARESTESIAS
↓
RED FLAGS? (frío/pálido, herida, luxación, fiebre, no movimiento) → URGENTE / MÉDICO
↓ NO
LOCALIZACIÓN EXACTA (dedo + zona)
↓
¿DOMINA HORMIGUEO NOCTURNO MEDIANO?
↓ SÍ → STC CLUSTER (Phalen/Tinel apoyan; no confirman) + cribado cervical
↓ NO
¿CHASQUIDO/BLOQUEO NUDILLO?
↓ SÍ → TRIGGER / A1
↓ NO
¿TRAUMA RECIENTE?
↓ SÍ → JERSEY / MALLET / UCL / IF según mecanismo + tests activos
↓ NO
ESGUINCE / SOBRECARGA / ARTROSIS IF según patrón
↓
HIPÓTESIS (H1–H4) + COEXISTENCIA (p. ej. STC + trigger)
↓
CONFIANZA + SIGUIENTE PASO
```

## 13. RED FLAGS

- Dedo frío, pálido o cianótico (vasoespasmo / vascular)  
- Herida abierta, sangrado severo, hueso expuesto  
- Luxación visible o deformidad grave  
- Incapacidad total de movimiento post trauma mayor  
- Fiebre + celulitis / infección  
- Jersey finger sospechado (FDP) → derivación médica  
- Mallet con fractura abierta o neurovascular comprometido  
- UCL completa + inestabilidad funcional severa

---

## 14. IMAGING

| Modalidad | Cuándo considerar |
|-----------|-------------------|
| **RX** | Mallet, UCL, trauma IF, luxación |
| **US** | UCL parcial, tendón FDP, A1 |
| **RMN** | Duda tendón, UCL completa, persistencia |
| **Clínica** | Primera línea = historia + examen activo |

**Regla:** imagen no sustituye tests activos IFP/IFD ni cluster clínico.

---

## 15. COEXISTING PATHOLOGY

Permitir:

- STC + trigger en otro dedo  
- De Quervain + dolor pulgar (ver `wrist-dequervain.md`)  
- Esguince IF + contusión leve  
- Cervical referido + síntomas digitales atípicos  

**Entidad dominante** + **coexistente** + **incierta** + **requiere más valoración**.

---

## 16. AI LANGUAGE RULES

**Usar:**

- «Los hallazgos son compatibles con trigger finger / tenosinovitis A1…»  
- «Phalen y Tinel apoyan túnel carpiano en cluster; un test negativo no lo descarta.»  
- «La incapacidad de flexionar activamente la articulación de la punta sugiere sospecha de jersey finger — valoración médica.»  
- «Este resultado debe interpretarse con el mecanismo y el dolor familiar.»

**Evitar:**

- «Phalen positivo = tienes túnel carpiano.»  
- «Tinel confirma STC.»  
- «Es un esguince leve» sin descartar jersey/mallet/UCL en trauma.  
- «UCL positivo = rotura confirmada» sin contexto.

## 17. FINAL CLASSIFICATION

| Clasificación | Criterio orientativo |
|---------------|---------------------|
| **LOW RISK / INFO** | Esguince leve, sin RF, autocuidado + reevaluación |
| **PHYSIOTHERAPY ASSESSMENT** | Trigger, IF, función limitada, patrón MSK |
| **MEDICAL ASSESSMENT** | Jersey, mallet, UCL, duda tendón, persistencia |
| **URGENT / EMERGENCY** | Vascular, infección, luxación, trauma mayor |
