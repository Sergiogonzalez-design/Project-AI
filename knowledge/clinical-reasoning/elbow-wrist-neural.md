# PHYSIOGUIDE AI — ELBOW / WRIST NEURAL (CTS, CUBITAL, CERVICAL)

**Status:** ACTIVE  
**Evidence:** Phalen, Tinel mediano/cubital, ULTT, Spurling; clusters STC / cubital / cervical — ver `knowledge/evidence/elbow-wrist-tests.md`, `knowledge/evidence/clusters-elbow-wrist.md`  
**Principles:** Ver `knowledge/PHYSIOGUIDE_MASTER_CLINICAL_DOCUMENT.md`

---

## 1. DEFINITION

**Síntomas neurales de antebrazo/mano** = parestesias, entumecimiento, debilidad o dolor con distribución neuroanatómica que puede deberse a **compresión periférica local** (túnel carpiano / nervio mediano, túnel cubital / nervio cubital) o **referido/proximal** (cervical radiculopatía C6–C7, doble crush).

No es un diagnóstico único. La **historia** (noche, sacudir la mano, territorio exacto, posición del codo) pesa tanto o más que un test aislado.

---

## 2. TERRITORY MAPPING (obligatorio)

Preguntar siempre:

> «¿Qué dedos hormiguean? ¿De noche? ¿Sacudes la mano para aliviar?»

| Territorio | Nervio / origen orientativo |
|------------|----------------------------|
| Pulgar, índice, medio (± mitad anular) | Mediano / STC |
| Anular + meñique (4.º–5.º) | Cubital / túnel cubital |
| Dorso mano / dedos extensión | Radial / PIN / C6–C7 |
| Irradiación brazo completo + cuello | Cervical |
| Solo meñique aislado | Cubital (no STC) |
| Solo pulgar debilidad | Mediano (STC avanzado) |

**Regla:** meñique solo ≠ STC. Diagrama de Katz ayuda pero no sustituye historia.

---

## 3. HISTORY (obligatoria)

- Inicio: agudo vs insidioso  
- **Síntomas nocturnos** (despertar, sacudir mano) — muy relevante STC  
- Territorio exacto de parestesias  
- Debilidad: agarre, pinza, caída de objetos, abducción pulgar  
- Empeora al flexionar codo / apoyar codo en mesa (cubital)  
- Empeora con actividades repetitivas mano/muñeca  
- Cervicalgia, irradiación proximal, empeora al girar cabeza  
- Trauma previo codo/muñeca  
- Condiciones asociadas STC: embarazo, tiroides, DM (contexto, sin alarmismo)  
- Pregunta clave: **«¿Es el mismo hormigueo que te despierta por la noche?»**

---

## 4. MECHANISM

| Mecanismo | Hipótesis ↑ |
|-----------|-------------|
| Uso repetitivo mano/muñeca + nocturno | STC |
| Flexión prolongada codo (dormir, mesa) | Túnel cubital |
| Cuello + brazo | Cervical radiculopatía |
| Trauma codo (golpe) | Cubital agudo |
| Doble crush (cuello + distal) | Cervical + STC/cubital |
| Sin mecanismo + progresión rápida | Medical/neuro screen |

## 5. CARPAL TUNNEL SYNDROME (STC)

**Definición clínica:** síntomas compatibles con compresión del nervio mediano en el túnel carpiano: parestesias en territorio mediano, frecuentemente nocturnas, con posible debilidad de agarre/pulgar.

**Patrón compatible:**

```
PARESTESIAS NOCTURNAS TERRITORIO MEDIANO
± SACUDIR LA MANO ALIVIA
± PHALEN FAMILIAR
± TINEL MEDIANO FAMILIAR
± DIAGRAMA KATZ COMPATIBLE
→ STC COMPATIBILITY ↑
```

**Hallazgos de gravedad:**

- Déficit abducción pulgar (thenar)  
- Atrofia tenar  
- Pérdida de pinza fina

**Reglas críticas:**

- Phalen/Tinel **negativos no descartan** STC  
- Historia nocturna + territorio mediano pesa mucho (D'Arcy & McGee JAMA; Erickson JOSPT CTS CPG)  
- Meñique solo → cubital, no STC

---

## 6. TÚNEL CUBITAL / NEUROPATÍA CUBITAL

**Typical:** parestesias 4.º–5.º dedo, empeora al flexionar codo o apoyarlo, debilidad intrínsecos mano en casos avanzados.

**Patrón compatible:**

```
PARESTESIAS 4.º–5.º DEDO
+ EMPEORA AL FLEXIONAR O APOYAR EL CODO
± TINEL CUBITAL (canal) FAMILIAR
± ELBOW FLEXION TEST FAMILIAR
→ TÚNEL CUBITAL COMPATIBILITY ↑
```

**Diferencial obligatorio:**

- Epicondilalgia medial (dolor, no parestesias dominantes)  
- C8/T1 cervical  
- Guyon canal (muñeca, no codo)

**Regla:** no etiquetar 4.º–5.º como STC.

---

## 7. CERVICAL REFERRED / RADICULOPATHY

Screen cuando:

- Cervicalgia concurrente  
- Irradiación brazo no estrictamente mediano/cubital  
- Spurling positivo / ULTT familiar  
- Tests locales codo/muñeca poco familiares  
- Déficit reflejos / fuerza segmentaria

**Patrón compatible:**

```
CUELLO + HORMIGUEO NO ESTRICTAMENTE MEDIANO/CUBITAL
± SPURLING / ULTT FAMILIAR
+ TESTS LOCALES (Phalen, Cozen) POCO FAMILIARES
→ CERVICAL REFERRAL ↑
```

**Regla:** Wainner 2003 — ULTT aislado poco específico; integrar con historia cervical.

---

## 8. DOUBLE CRUSH / COEXISTENCE

Permitir:

- Cervical leve + STC  
- STC + epicondilalgia (uso repetitivo)  
- Cubital + medial epicondylalgia  
- STC unilateral + trabajo bilateral (considerar bilateralidad)

**Dominant entity:** el que explica mejor territorio + noche + exploración.

---

## 9. PALPATION & PROVOCATION

| Test / zona | Qué buscar |
|-------------|------------|
| Tinel mediano (muñeca) | Parestesias territorio mediano familiar |
| Phalen (flexión muñecas) | Reproducción síntoma STC familiar |
| Tinel cubital (canal) | 4.º–5.º familiar |
| Elbow flexion (90 s) | Cubital provocation |
| Cervical PA / Spurling | Reproducción brazo familiar |
| Thenar | Atrofia, debilidad abducción pulgar |

**Familiar pain/symptom** en provocación aumenta peso clínico; no confirma compresión quirúrgica.

## 10. SPECIAL TESTS

### Phalen

- **Purpose:** provocar STC  
- **Positive:** parestesias mediano familiar en 60 s  
- **AI rule:** apoya STC en cluster; negativo no descarta

### Durkan / compresión carpiana

- **Purpose:** complemento de Phalen/Tinel (presión mantenida sobre el túnel)  
- **Positive:** parestesias **familiares** en 1.º–3.º (no dolor local de muñeca solo)  
- **AI rule:** cluster STC con historia nocturna (D’Arcy JAMA; JOSPT CTS 2019). Evidencia de precisión **mixta**. Negativo no descarta. Meñique solo ≠ STC.  
- **Citation:** Durkan 1991; MacDermid; Erickson JOSPT CTS CPG 2019; `elbow-wrist-tests-expansion.md`

### Tinel mediano

- **Purpose:** percusión nervio mediano  
- **Positive:** parestesias territorio mediano  
- **AI rule:** complemento de Phalen; menos sensible que historia nocturna

### Tinel cubital / elbow flexion

- **Purpose:** provocar cubital  
- **Positive:** 4.º–5.º familiar  
- **AI rule:** compatible con túnel cubital; no confirma grado

### Froment (± Wartenberg)

- **Purpose:** cribado **motor** cubital (aductor del pulgar)  
- **Positive:** flexión IFP del pulgar al pinzar papel (compensa con FPL)  
- **AI rule:** motor cubital; **no** localiza codo vs Guyon — usa historia (flexión codo vs presión palmar). Ver `elbow-wrist-guyon.md`

### Spurling / ULTT

- **Purpose:** cervical radiculopatía  
- **Positive:** reproducción síntoma brazo familiar  
- **AI rule:** sube cervical; no forzar STC/LET

---

## 11. FUNCTIONAL TESTS

- Agarre prolongado (conducción, herramientas)  
- Pinza fina (móvil, botones)  
- Trabajo nocturno / despertares  
- Posición de sueño (codo flexionado)  
- Actividades que empeoran cuello

---

## 12. TEST CLUSTERS

### Cluster A — STC

1. Parestesias nocturnas territorio mediano  
2. Sacudir mano (opcional)  
3. **Durkan** y/o Phalen y/o Tinel familiar  
4. Katz compatible  
5. Sin 4.º–5.º aislado  

→ **STC compatibility ↑**

Historia nocturna pesa tanto o más que cualquier test. Durkan/Phalen/Tinel **apoyan**; no confirman.

### Cluster B — Túnel cubital

1. Parestesias 4.º–5.º  
2. Empeora flexión/apoyo codo  
3. Tinel cubital / elbow flexion familiar  

→ **Túnel cubital compatibility ↑**

### Cluster C — Cervical

1. Cuello + irradiación brazo  
2. Spurling/ULTT familiar  
3. Tests locales poco familiares  

→ **Cervical referral ↑**

**Clasificación:** combinación clínica; no inventar Sn/Sp.

---

## 14. RED FLAGS

- Déficit motor marcado (caída objetos, thenar atrofiado)  
- Progresión rápida de debilidad  
- Dolor nocturno severo + pérdida peso (medical)  
- Trauma mayor + déficit inmediato  
- Síntomas bilaterales agudos + medical context  
- Pérdida sensitiva completa en territorio

## 15. IMAGING / REFERRAL

| Estudio | Cuándo considerar |
|---------|-------------------|
| **EMG/NCS** | Duda STC vs cubital vs cervical; pre-quirúrgico |
| **US nervio** | Contexto especializado |
| **MRI cervical** | Sospecha radiculopatía con déficit |
| **Clinical** | Primera línea = historia + territorio + cluster |

**Regla:** EMG anormal ≠ siempre quirúrgico; correlacionar clínica.

## 16. AI LANGUAGE RULES

**Usar:**

- «Compatible con túnel carpiano…»  
- «Aumenta la sospecha de neuropatía cubital en el codo…»  
- «Phalen negativo no descarta STC si la historia es típica…»  
- «El cuadro sugiere componente cervical; hay que integrarlo…»

**Evitar:**

- «Tienes túnel carpiano confirmado.»  
- «Phalen positivo = STC.»  
- «Meñique = túnel carpiano.»

---

## 17. FINAL CLASSIFICATION

| Clasificación | Criterio orientativo |
|---------------|---------------------|
| **LOW RISK / INFO** | Parestesias leves, intermitentes, sin déficit |
| **PHYSIOTHERAPY ASSESSMENT** | STC/cubital leve-moderado, ergonomía, neural mobilization |
| **MEDICAL ASSESSMENT** | Déficit motor, persistencia, duda diagnóstica, EMG |
| **URGENT** | Déficit motor agudo progresivo, trauma con déficit |
