# PHYSIOGUIDE AI — ARTROSIS / OSTEOARTRITIS DE CODO

**Status:** ACTIVE (Phase 1)  
**Evidence:** clínica + imagen cuando procede; ver `knowledge/evidence/elbow-wrist-tests-expansion.md` (sección OA)  
**Principles:** Ver `knowledge/PHYSIOGUIDE_MASTER_CLINICAL_DOCUMENT.md`

---

## 1. DEFINITION

**Artrosis / osteoartritis (OA) de codo** = dolor mecánico del codo asociado a **pérdida de movilidad**, crepitación y/o carga axial/compresión, habitualmente en edad media-avanzada o post-traumática (fractura previa, inestabilidad crónica), que puede coexistir con tendinopatía o bursitis pero **no** se confirma por Cozen/Mill.

No es un cluster de tests especiales validado como el UCL o el hook. El diagnóstico clínico se apoya en **historia + ROM + crepitación + carga**, y la **RX** cuando se necesita confirmar cambios estructurales o planificar manejo.

---

## 2. TYPICAL LOCATION

| Ubicación | Interpretación |
|-----------|----------------|
| Global / «todo el codo» + rigidez | OA / artrosis compatible |
| Epicóndilo lateral solo + agarre | LET primero (otro módulo) |
| Olecranon + hinchazón fluctante | Bursitis (puede coexistir) |
| Anterior + pop | Bíceps distal — no OA |

---

## 3. HISTORY

- Edad, trabajo manual, deporte de impacto, fractura/luxación previa  
- Rigidez matutina breve vs inflamatoria prolongada  
- Bloqueo / sensación de «arena» / crepitación  
- Dolor al cargar (empuje, apoyo en silla) más que solo al agarrar  
- Inflamación, fiebre, calor marcado → no OA aislada (sepsis / inflamatorio)  
- Pregunta clave: **«¿El codo te ha ido perdiendo movilidad y duele al apoyarte o cargar, más que solo al agarrar?»**

---

## 4. MECHANISM / PATTERN

| Patrón | Hipótesis ↑ |
|--------|-------------|
| Insidioso + pérdida ROM + crepitación | OA primaria / post-traumática |
| Fractura antigua / inestabilidad crónica | OA secundaria |
| Solo agarre + epicóndilo, ROM casi normal | LET / medial |
| Fiebre + calor + derrame agudo | Infección / artritis inflamatoria |

---

## 5. RED FLAGS

- Fiebre, codo caliente, derrame agudo, herida → **urgencia médica** (no etiquetar OA)  
- Bloqueo duro + trauma reciente → cuerpo libre / fractura / luxación  
- Déficit neurológico / vascular  

---

## 6. CLINICAL CLUSTER (cualitativo — no Sn/Sp inventados)

```
EDAD MEDIA-AVANZADA O ANTECEDENTE ÓSEO/INESTABILIDAD
+ DOLOR MECÁNICO CON CARGA / APOYO
+ PÉRDIDA DE ROM (flexión-extensión y/o pronosupinación) vs contralateral
± CREPITACIÓN / BLOQUEO INTERMITENTE
± RX CON CAMBIOS DEGENERATIVOS (si se indica)
→ OA DE CODO COMPATIBILITY ↑
```

**No existe** un test especial único (tipo Cozen) que confirme OA. La exploración de ROM y carga es clínica estándar (Morrey / revisiones de codo); la precisión de «crepitación = OA» **no** debe citarse con cifras inventadas.

---

## 7. DIFFERENTIAL

| Entidad | Discriminador |
|---------|----------------|
| LET / medial | Dolor epicóndilo + carga tendinosa; ROM suele conservarse |
| PLRI / UCL | Inestabilidad / aprensión, no solo crepitación |
| Bursitis olecraneana | Hinchazón punta; ROM puede ser buena |
| Cabeza radial / cuerpo libre | Bloqueo mecánico post-trauma |
| Artritis inflamatoria / infección | Sistémico, calor, derrame |

---

## 8. IMAGING / ACTION

- RX de codo si rigidez persistente, duda estructural o plan quirúrgico  
- RMN/eco si sospecha tendón/cuerpo libre más que OA  
- Fisioterapia: movilidad, carga tolerada, no «confirmar OA» solo con un test de tendón  

---

## 9. AI RULES

- Nunca: Cozen/Mill positivo = artrosis.  
- Nunca: crepitación aislada = OA confirmada sin contexto.  
- Nunca inventar Sn/Sp ni LR para OA de codo.  
- Lenguaje: «compatible con artrosis / cambios degenerativos de codo», «pérdida de movilidad mecánica»; no «OA confirmada» sin imagen cuando la decisión clínica lo requiera.

**Citation:** Morrey BF — exploración y artrosis de codo (texto clínico estándar). Revisiones de osteoartritis de codo (JSES / Hand Clinics): diagnóstico clínico + radiográfico; no cluster de tests especiales con métricas robustas publicadas como en LCA. Zwerus et al. — evidencia de muchos tests de codo limitada; no usar como sustituto de RX cuando hay rigidez estructural.
