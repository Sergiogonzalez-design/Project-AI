# PHYSIOGUIDE AI — TÚNEL RADIAL / PIN vs LET

**Status:** ACTIVE (Phase 1)  
**Evidence:** Maudsley, supinación resistida, palpación arcade of Frohse; cluster C  
**Principles:** Master clinical document

---

## 1. DEFINITION

**Síndrome del túnel radial** = dolor en antebrazo proximal dorsal por irritación del nervio radial / ramo interóseo posterior (PIN) a nivel del supinador (arcade of Frohse), **sin** (o con poco) déficit motor.

**PIN clásico** = más **motor** (extensión de dedos/muñeca, desviación radial por ERC conservado).

Ambos se **solapan con LET** porque Maudsley y Cozen cargan ECRB y el túnel radial.

---

## 2. DISCRIMINACIÓN CLÍNICA

| Hallazgo | LET ↑ | Túnel radial / PIN ↑ |
|----------|-------|----------------------|
| Dolor máximo | Epicóndilo óseo | Antebrazo proximal dorsal |
| Palpación | Epicóndilo / ECRB | Arcade of Frohse / supinador |
| Maudsley | Dolor en hueso | Dolor muscular proximal |
| Déficit extensión dedos | No | PIN |
| Cuello / Spurling | C6–C7 | C6–C7 también |

---

## 3. CLUSTER

```
DOLOR ANTEBRAZO PROXIMAL DORSAL > EPICÓNDILO
+ PALPACIÓN SOBRE TÚNEL RADIAL
± MAUDSLEY / COZEN CON DOLOR NO ÓSEO
± SUPINACIÓN RESISTIDA DOLOROSA
SIN (túnel) O CON (PIN) DEBILIDAD DE EXTENSORES
→ NEURAL RADIAL COMPATIBILITY ↑
SIEMPRE CRIBAR CUELLO
```

---

## 4. AI RULES

- Maudsley positivo **no** significa nervio radial lesionado.  
- LET y túnel radial pueden coexistir.  
- Debilidad franca de extensión de dedos → PIN / C7, no “tendinitis”.  
- No inventar Sn/Sp.
