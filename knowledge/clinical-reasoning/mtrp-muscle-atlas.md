**Capa:** Clínica transversal (atlas propio — no libro protegido)  
**Status:** ACTIVE  
**Companion:** [`mtrp-framework.md`](./mtrp-framework.md)  
**Copyright:** No texto Travell & Simons. Patrones referidos = **TRADICIONAL** salvo cita clínica/experimental explícita.

---

## REGLAS DE USO

- Cada entrada es **hipótesis**, no diagnóstico.  
- **MTrP encontrado ≠ causa demostrada.**  
- Mapas tradicionales ≠ anatomía absoluta.  
- Exigir **dolor familiar** a la palpación antes de elevar la hipótesis.  
- Diferencial articular/neural/tendíneo siempre disponible.  
- Controversia: criterios variables; fiabilidad de palpación limitada (Tough 2007; Lucas 2009).

Formato por músculo:

```
### Nombre
- Local / referido (TRADICIONAL salvo nota)
- Puede mimetizar
- Diferenciar
- Limitaciones
```

## 1. CERVICAL / CRÁNEO

### Trapecio superior
- Local / referido (TRADICIONAL): ángulo cuello–hombro → cuello lateral, temporal, detrás de oreja, hombro  
- Puede mimetizar: cefalea tensional/cervicogénica, C-spine, AC  
- Diferenciar: dolor familiar; AROM cervical; cribado hombro/AC; red flags cefalea  
- Limitaciones: evidencia causal insuficiente; no diagnosticar migraña como trapecio  

### Elevador de la escápula
- Local / referido (TRADICIONAL): ángulo superior escápula → cuello posterolateral / hombro  
- Puede mimetizar: faceta cervical, AC, manguito  
- Diferenciar: cuello vs hombro; dolor familiar; Spurling/cluster si neural  
- Limitaciones: mapas no absolutos  

### Esplenio cabeza / cuello
- Local / referido (TRADICIONAL): cervical posterior → occipucio / vértex  
- Puede mimetizar: cervicogénica, tensional  
- Diferenciar: C0–C2; red flags; criterios cefalea  
- Limitaciones: D / insufficient causal  

### Semiespinoso / multifidus cervical
- Local / referido (TRADICIONAL): axial → cabeza  
- Puede mimetizar: facetario, cefalea primaria  
- Diferenciar: neurológico; mecánica cervical  
- Limitaciones: palpación poco específica  

### Suboccipitales
- Local / referido (TRADICIONAL): C0–C2 → occipucio / órbita  
- Puede mimetizar: cervicogénica, migraña, vascular  
- Diferenciar: seguridad primero; AROM alto  
- Limitaciones: nunca priorizar si red flags  

### ECM (esternocleidomastoideo)
- Local / referido (TRADICIONAL): cuello anterior → frente, órbita, oído, vértigo subjetivo (mapa clásico)  
- Puede mimetizar: vestibular, ATM, migraña, vascular  
- Diferenciar: seguridad; ATM; cervical; no atribuir vértigo solo a ECM  
- Limitaciones: alta responsabilidad diferencial  

### Escalenos
- Local / referido (TRADICIONAL): lateral cuello → brazo / pecho  
- Puede mimetizar: radiculopatía, TOS, cardíaco  
- Diferenciar: neurológico, ULTT, red flags pecho  
- Limitaciones: no mapear pecho a músculo sin seguridad

## 2. HOMBRO / ESCAPULAR

### Infraespinoso
- Local / referido (TRADICIONAL): fosa infraespinosa → deltoides lateral / brazo  
- Puede mimetizar: RCRSP, cervical, AC  
- Diferenciar: cluster manguito (Lewis/Hegedus cualitativo); cribado cervical; dolor familiar  
- Limitaciones: piloto hombro lateral — hipótesis débil vs RCRSP/cervical  

### Supraespinoso
- Local / referido (TRADICIONAL): fossa → hombro lateral / codo  
- Puede mimetizar: RCRSP, C5  
- Diferenciar: Jobe/arco cualitativo; neural  
- Limitaciones: solapamiento total con tendinopatía  

### Redondo menor / mayor
- Local / referido (TRADICIONAL): axila posterior → hombro  
- Puede mimetizar: manguito, inestabilidad posterior  
- Diferenciar: cluster inestabilidad; RCRSP  
- Limitaciones: tradicional  

### Deltoides
- Local / referido (TRADICIONAL): vientre → local / brazo  
- Puede mimetizar: RCRSP referido a «deltoides»  
- Diferenciar: manguito vs cervical primero  
- Limitaciones: dolor «en el deltoides» ≠ deltoides causal  

### Subescapular
- Local / referido (TRADICIONAL): axila anterior → hombro / muñeca (mapa clásico)  
- Puede mimetizar: subacromial, bíceps, cervical  
- Diferenciar: RI/lift-off cualitativo; neural  
- Limitaciones: no usar mapa de muñeca como anatomía  

### Pectoral mayor / menor
- Local / referido (TRADICIONAL): pecho → hombro anterior / brazo  
- Puede mimetizar: cardíaco, AC, inestabilidad anterior  
- Diferenciar: **red flags cardíacos**; hombro  
- Limitaciones: seguridad > miofascial  

### Serrato anterior
- Local / referido (TRADICIONAL): lateral tórax → escápula medial  
- Puede mimetizar: radicular, disfunción escapular  
- Diferenciar: winging, neural, cervical  
- Limitaciones: tradicional  

### Romboideos
- Local / referido (TRADICIONAL): borde medial escápula → local  
- Puede mimetizar: facetario torácico, cervical referido  
- Diferenciar: AROM C/T; neural  
- Limitaciones: «dolor entre omóplatos» multifactorial  

*(Ver también [`../evidence/referred-pain-shoulder-lateral.md`](../evidence/referred-pain-shoulder-lateral.md))*

## 3. LUMBAR / TRONCO

### Erector spinae / longissimus
- Local / referido (TRADICIONAL): paravertebral → glúteo / flanco  
- Puede mimetizar: faceta, disco, visceral  
- Diferenciar: red flags; AROM; neural  
- Limitaciones: D causal  

### Multifidus lumbar
- Local / referido (TRADICIONAL): segmentario → axial / glúteo  
- Puede mimetizar: faceta  
- Diferenciar: cluster LBP (JOSPT); no diagnóstico facetario por palpación  
- Limitaciones: controversia MTrP  

### Cuadrado lumbar
- Local / referido (TRADICIONAL): flanco → cresta ilíaca / glúteo  
- Puede mimetizar: faceta, SIJ, renal  
- Diferenciar: visceral/seguridad; lateral flexión; SIJ/lumbar  
- Limitaciones: mapas ≠ anatomía  

### Iliopsoas
- Local / referido (TRADICIONAL): ingle/lumbar → muslo anterior  
- Puede mimetizar: FAI/OA, hernia, visceral  
- Diferenciar: FADIR; abdominal; Doha groin  
- Limitaciones: no «psoas = ingle» automático

## 4. GLÚTEO / CADERA

### Glúteo medio / menor
- Local / referido (TRADICIONAL): vientre → trocánter / muslo lateral  
- Puede mimetizar: GTPS/tendinopatía, L4–L5  
- Diferenciar: carga abd/SLS; lumbar; dolor familiar  
- Limitaciones: priorizar tendón si cluster GTPS  

### Glúteo mayor
- Local / referido (TRADICIONAL): nalga → local / sacro  
- Puede mimetizar: SIJ, radicular  
- Diferenciar: neural; SIJ cluster cualitativo  
- Limitaciones: tradicional  

### Piriforme / rotadores externos
- Local / referido (TRADICIONAL): glúteo profundo → muslo posterior / pierna  
- Puede mimetizar: S1, deep gluteal, SIJ  
- Diferenciar: neurológico lumbar completo; **no** «piriforme = ciática»  
- Limitaciones: alta controversia; evidencia atrapamiento limitada  

### TFL
- Local / referido (TRADICIONAL): TFL → muslo lateral / rodilla  
- Puede mimetizar: ITBFS, GTPS, menisco lateral  
- Diferenciar: ITB clínico vs menisco vs lumbar  
- Limitaciones: mapa MTrP D  

### Aductores
- Local / referido (clínico strain / TRADICIONAL fino): ingle → muslo medial  
- Puede mimetizar: cadera articular, hernia  
- Diferenciar: Doha; FADIR; abdominal  
- Limitaciones: ingle multi-generador

## 5. MUSLO

### Cuádriceps (RF / VL / VM)
- Local / referido (TRADICIONAL): vientre → rodilla anterior  
- Puede mimetizar: PFP, tendón rotuliano, cadera referida  
- Diferenciar: PFP CPG; FADIR; dolor familiar  
- Limitaciones: MTrP ≠ PFP demostrado  

### Isquiotibiales
- Local / referido (clínico strain / TRADICIONAL fino): vientre → fosa poplítea  
- Puede mimetizar: S1, menisco posterior  
- Diferenciar: neural; fuerza; derrame  
- Limitaciones: no mapear a menisco  

### Sartorio / pectíneo
- Local / referido (TRADICIONAL): muslo anterior/medial → rodilla medial  
- Puede mimetizar: anserina, menisco, cadera  
- Diferenciar: local rodilla + cadera  
- Limitaciones: tradicional

## 6. PANTORRILLA / PIE

### Gastrocnemio
- Local / referido (TRADICIONAL): pantorrilla → talón / planta  
- Puede mimetizar: Aquiles, TVP, S1  
- Diferenciar: red flags vasculares; Thompson/Aquiles; neural  
- Limitaciones: seguridad > mapa  

### Sóleo
- Local / referido (TRADICIONAL): profundo → talón  
- Puede mimetizar: Aquiles insertional, plantar heel  
- Diferenciar: tendón vs fascia vs vascular  
- Limitaciones: tradicional  

### Peroneos
- Local / referido (clínico tendón / TRADICIONAL MTrP): lateral → pie lateral  
- Puede mimetizar: ATFL, 5º MTT, sural  
- Diferenciar: Ottawa; eversión resistida  
- Limitaciones: no confundir con fractura  

### Tibial posterior
- Local / referido (clínico): maléolo medial → arco  
- Puede mimetizar: fascial, túnel tarsiano  
- Diferenciar: heel rise; neural  
- Limitaciones: —  

### Intrínsecos del pie
- Local / referido (TRADICIONAL): planta → antepié  
- Puede mimetizar: Morton, stress MTT  
- Diferenciar: palpación espacios; Ottawa/stress  
- Limitaciones: MTrP ≠ neuroma

## 7. ANTEBRAZO / MANO

### Extensores / ECRB / ED
- Local / referido (TRADICIONAL): antebrazo dorsal → epicóndilo / dorso mano  
- Puede mimetizar: LET, radial tunnel, C6  
- Diferenciar: Cozen cualitativo; neural; cervical  
- Limitaciones: solapamiento LET  

### Flexores / FCR / FDS
- Local / referido (TRADICIONAL): antebrazo volar → epicóndilo medial / dedos  
- Puede mimetizar: MED, CTS, cubital  
- Diferenciar: tendón vs nervio vs cervical  
- Limitaciones: no MTrP = CTS  

### Supinador
- Local / referido (TRADICIONAL): proximal → dorso antebrazo  
- Puede mimetizar: radial tunnel, LET  
- Diferenciar: localización dolor; neural  
- Limitaciones: entidad radial tunnel controvertida  

### Intrínsecos mano / tenar / hipotenar
- Local / referido (TRADICIONAL): local → dedos  
- Puede mimetizar: CTS, Guyon, C8  
- Diferenciar: distribución sensitiva; cervical  
- Limitaciones: tradicional

## AI rule (atlas)

Usar entradas solo para **ampliar hipótesis** cuando el modo claridad no aplica. Etiquetar TRADICIONAL. Exigir dolor familiar. Ofrecer 1 diferencial no miofascial. Nunca pegar ni parafrasear prosa de atlas comerciales protegidos. Citar Tough/Lucas para límites de palpación.
