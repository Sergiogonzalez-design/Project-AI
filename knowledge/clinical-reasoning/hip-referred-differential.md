## 1. ESCENARIO

Dolor de **ingle**, **trocánter**, **glúteo** o **muslo proximal** donde FADIR/FABER/Trendelenburg son negativos, hay pistas lumbares, o no hay imagen.

**No responder:** «Es FAI» o «es el piriforme.»  
**Sí:** entidades clínicas (Doha) + lumbar + red flags óseas, con evidencia etiquetada.

---

## 2. HIPÓTESIS A CONSIDERAR (priorizar)

| Prioridad típica | Hipótesis | Cuándo subir |
|------------------|-----------|--------------|
| 0 | Red flags óseas | No carga, trauma, AVN (esteroides/alcohol/drepanocitosis), infección |
| 1 | Lumbar referido / radicular | Movimiento lumbar cambia ingle/trocánter; neuro |
| 2 | Intraarticular / FAI syndrome | Ingle/C-sign + carga flex-AD-IR; Warwick = síndrome, no morfología |
| 3 | Adductor / iliopsoas / inguinal / púbico (Doha) | Atleta; checklist de entidades; coexistencia OK |
| 4 | GTPS | Lateral, decúbito lateral, stance; Trendelenburg− no excluye |
| 5 | SIJ / FABER multi-estructura | Interpretar por localización del dolor |
| 6 | Piriformis / deep gluteal (tradicional) | Solo D tras lumbar; alta controversia |

**Coexistencia permitida:** adductor-related + hip joint-related; lumbar + cadera.

---

## 3. PRUEBAS NEGATIVAS

- FADIR − → **no** limpia articulación.  
- FABER − → **no** excluye cadera ni SIJ.  
- Trendelenburg − → **no** excluye GTPS.  
- Exigir **dolor familiar** y mapa de localización.

---

## 4. FLUJO

```
Red flags (fractura / AVN / infección)
→ ¿Lumbar contribuye? (AROM + neuro)
→ FADIR/FABER/squat con dolor familiar (Warwick)
→ Checklist Doha si ingle de deportista
→ GTPS cluster si lateral
→ Piriformis solo D + familiar pain
→ HIPÓTESIS PRINCIPAL / ALTERNATIVA / NO PRIORITARIO
→ Si no mejora: reevaluación (no solo más morfología de cadera)
```

## AI RULE

En duda ingle/cadera/GTPS: seguridad ósea primero; FADIR− no excluye; Doha multi-entidad; lumbar coexistente; piriformis solo tradicional/D. Fuente: pack relations `hip` v2.
