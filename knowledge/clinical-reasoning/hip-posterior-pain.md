## 1. DEFINITION

**Posterior hip pain** = dolor en región posterior de cadera, glúteo, tuberosidad isquiática o zona profunda glútea, que puede deberse a patología **local** (isquiotibiales proximales, deep gluteal syndrome, ischiofemoral impingement, cuádriceps femoral posterior) o **referida/neural** (lumbar, SI, ciático, radiculopatía).

No es un diagnóstico único.

---

## 2. TYPICAL LOCATION

Preguntar: «Señala con un dedo dónde te duele.»

| Ubicación | Interpretación orientativa |
|-----------|---------------------------|
| Tuberosidad isquiática / al sentarse | Isquiotibiales proximales, avulsión (trauma) |
| Glúteo medio-alto profundo | Deep gluteal / piriformis / ciático |
| Glúteo inferior / posterolateral | Isquiofemoral / cuádriceps femoris |
| Posterior cadera profunda | Cadera posterior / SI |
| Irradiación muslo posterior | Ciático / lumbar / isquiotibial |
| Lumbar asociado | Referido lumbar / radicular |

**Regla:** glúteo posterior ≠ piriformis automáticamente.

---

## 3. HISTORY

- Inicio y mecanismo (sprint, chute, caída, sentarse prolongado, carrera)  
- Evolución  
- **Dolor al sentarse** (superficie dura vs blanda)  
- Dolor al estirar isquiotibial  
- Caminar, correr, sprint, cambio de dirección  
- Hormigueo, entumecimiento, debilidad  
- Síntomas lumbares  
- Dolor nocturno / pérdida peso (red flags)  
- **Familiar pain:** «¿Es el mismo dolor de tu actividad?»

---

## 4. MECHANISM

| Mecanismo | Hipótesis ↑ |
|-----------|-------------|
| Sprint / chute / estirón | Distensión isquiotibial proximal |
| Sobrecarga progresiva / carrera | Tendinopatía isquiotibial proximal |
| Sentarse prolongado (conductor, ciclista) | Deep gluteal / ciático / isquio |
| Caída sobre isquion | Contusión, avulsión, fractura (screen) |
| Inicio insidioso + neural | Radicular / deep gluteal |

---

## 5. LOAD / ACTIVITY

Agravantes típicos isquiotibial proximal:

- Sentarse (especialmente superficie dura)  
- Estiramiento isquiotibial  
- Sprint / aceleración  
- Caminar cuesta arriba  

Deep gluteal / ciático:

- Sentarse prolongado  
- Dolor glúteo profundo al sentarse  
- Posible irradiación posterior muslo  

---

## 6. PROXIMAL HAMSTRING TENDINOPATHY

**Patrón compatible:**

```
POSTERIOR / ISCHIAL PAIN
+ PAIN WITH SITTING (hard surface)
+ PAIN WITH HAMSTRING STRETCH / LOAD
+ FAMILIAR PAIN
→ PROXIMAL HAMSTRING COMPATIBILITY ↑
```

**No confirmar** con una sola prueba resistida.

**Clasificación:** combinación clínica respaldada por evidencia de pruebas individuales.

---

## 7. PROXIMAL HAMSTRING STRAIN (AGUDO)

Considerar si:

- Mecanismo agudo (sprint, chute)  
- Dolor isquion agudo  
- Hematoma / palpación dolorosa  
- Limitación funcional  

Diferenciar de tendinopatía crónica por temporalidad y mecanismo.

---

## 8. DEEP GLUTEAL SYNDROME

**Definición funcional:** dolor profundo en glúteo con posible componente nervioso (ciático) en región profunda, empeorado con **sentarse**, sin patrón exclusivo de estiramiento isquiotibial.

**Patrón:**

```
DEEP BUTTOCK PAIN
+ WORSE WITH SITTING (hard chair)
+ POSSIBLE SCIATIC-LIKE SYMPTOMS
+ LESS CLEAR HAMSTRING STRETCH REPRODUCTION
→ DEEP GLUTEAL / SCIATIC IRRITATION COMPATIBILITY ↑
```

**No confundir con:** radiculopatía lumbar sin exploración; piriformis como etiqueta automática.

---

## 9. PIRIFORMIS-RELATED PAIN

Considerar cuando:

- Dolor glúteo profundo  
- Posible reproducción con rotación interna / FAIR context  
- Dolor al sentarse  

**Regla:** «piriformis syndrome» es diagnóstico de exclusión clínico; no confirmar por un solo test.

---

## 10. ISCHIOFEMORAL IMPINGEMENT

Considerar:

- Dolor posterolateral / profundo glúteo  
- Síntomas con extensión / rotación externa / aducción  
- Posible chasquido o compresión  
- Mecanismo compatible  

**Clasificación:** combinación clínica; evidencia limitada para tests aislados.

---

## 11. QUADRATUS FEMORIS PATHOLOGY

Considerar en dolor profundo posterolateral con síntomas mecánicos en posiciones de rotación/aducción; parte del diferencial de deep gluteal / ischiofemoral.

---

## 12. POSTERIOR HIP JOINT PATHOLOGY

Si dolor posterior + profundo + síntomas intraarticulares (chasquido, bloqueo, inguinal asociado) → cribar cadera con FABER/FADIR/ROM.

FABER con dolor **posterior** → SI/lumbar ↑, no cadera inguinal.

---

## 13. SI / LUMBAR REFERRAL

**Screen obligatorio** si:

- Dolor lumbar concurrente  
- SLR positivo  
- Parestesias distribución ciática  
- FABER reproduce dolor posterior sacroilíaco  

**Patrón:** dolor glúteo sin dolor isquial al sentarse/estirar + SLR positivo → lumbar/radicular ↑.

---

## 14. LUMBAR RADICULOPATHY / SCIATIC NERVE

Considerar:

- SLR / Lasègue positivo familiar  
- Parestesias muslo posterior / pierna  
- Déficit neurológico  
- Síntomas lumbares  

**Regla:** SLR positivo ≠ hernia discal confirmada; integrar examen neurológico completo.

---

## 15. PALPATION

| Zona | Qué buscar |
|------|------------|
| Tuberosidad isquiática | Tenderness familiar (isquio) |
| Isquiotibial proximal | Tendón/músculo |
| Glúteo profundo (evitar presión agresiva) | Reproducción familiar |
| SI / lumbar | Referido |

---

## 16. PRIMARY & SECONDARY TESTS

### SLR / Lasègue

- **Purpose:** tensión neural / radicular  
- **Positive:** dolor familiar posterior muslo/glúteo/radicular  
- **AI rule:** aumenta sospecha radicular/ciática; no confirma hernia

### FABER (registrar localización del dolor)

- Posterior → SI/lumbar  
- Inguinal → cadera (otro módulo)

### Kemp / lumbar screen

- Si dolor lumbar asociado

### Resisted knee flexion (isquio)

- Dolor isquial familiar → isquiotibial ↑

### Sitting test (functional)

- Dolor al sentarse superficie dura → isquio/deep gluteal según patrón

---

## 17. FUNCTIONAL TESTS

- Sentarse / levantarse  
- Estirar isquiotibial (toe touch / slump context)  
- Caminar / correr / sprint  
- Subir cuesta  
- Peso monopodal (si aplica)

Registrar **familiar pain**.

---

## 18. TEST CLUSTERS

### Cluster A — Isquiotibial proximal

1. Dolor isquion / posterior  
2. Dolor al sentarse (superficie dura)  
3. Dolor al estirar isquiotibial  
4. Mecanismo sobrecarga/sprint (si aplica)  

→ **Proximal hamstring compatibility ↑**

### Cluster B — Deep gluteal / ciático

1. Dolor glúteo profundo  
2. Empeora sentado (silla dura)  
3. Posible parestesia  
4. SLR puede ser positivo  

→ **Deep gluteal / sciatic irritation ↑** (diferenciar lumbar)

### Cluster C — Lumbar / radicular

1. SLR positivo familiar  
2. Síntomas lumbares  
3. Distribución neural  
4. Déficit neurológico (si presente)  

→ **Lumbar radiculopathy / sciatic ↑**

## 20. RED FLAGS

- Trauma mayor + no apoyo  
- Deformidad / luxación  
- Déficit neurológico progresivo  
- Cauda equina (silla de montar)  
- Fiebre / infección  
- Dolor nocturno progresivo + pérdida peso  
- Fractura/avulsión sospechada (adolescente sprint + pop)  
- Dolor vascular (pie frío, pulsos)

---

## 21. IMAGING

| Modalidad | Cuándo |
|-----------|--------|
| **RX** | Trauma, fractura sospecha |
| **MRI** | Persistencia isquio, avulsión, deep gluteal, labrum si duda |
| **US** | Isquiotibial proximal, dinámico |

Hallazgo en imagen ≠ causa automática.

---

## 22. COEXISTING PATHOLOGY

- Isquio + lumbar  
- Deep gluteal + GTPS lateral  
- SI + lumbar  
- Hip joint + posterior  

---

## 23. AI LANGUAGE RULES

**Usar:** «compatible con tendinopatía isquiotibial proximal», «aumenta sospecha de irritación ciática/deep gluteal», «requiere correlación clínica y exploración neurológica».

**Evitar:** «tienes piriformis», «SLR confirma hernia», «dolor al sentarse = isquio roto».

|-------|--------|
