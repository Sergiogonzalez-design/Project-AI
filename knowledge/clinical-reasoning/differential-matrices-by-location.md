# PHYSIOGUIDE — MATRICES DIFERENCIALES POR LOCALIZACIÓN

**Capa:** Razonamiento (matrices)  
**Status:** ACTIVE  
**Principio:** Listas de **fuentes posibles compatibles con historia/examen** — **no** listas de diagnóstico automático.

---

## REGLA GLOBAL DE SELECCIÓN

1. Filtrar por **historia** (mecanismo, irritabilidad, 24 h, red flags).  
2. Filtrar por **examen** (qué reproduce dolor familiar; neurológico; clusters).  
3. Elegir **hipótesis principal + máx. 2 alternativas** compatibles.  
4. El resto → «no prioritario» con una frase.  
5. Lenguaje: «compatible con», «podría explorarse».  
6. Si el cluster es coherente → **modo claridad** (ver [`clarity-and-no-overdiagnosis.md`](./clarity-and-no-overdiagnosis.md)).

### AI rule (priorización)

```
Principal (evidencia alta/moderada/baja) → Alt 1 → Alt 2 (opcional)
Cada una: por qué encaja · qué contradice · qué discrimina
No emitir >3 hipótesis activas salvo modo exploración explícito
```

## 1. DOLOR CERVICAL

| Tipo | Fuentes posibles (filtrar) |
|------|----------------------------|
| Articular / discógeno | Segmentos cervicales, facetas |
| Neural | Radiculopatía, mielopatía (seguridad) |
| Miofascial | Trapecio, elevador, escalenos, suboccipitales |
| Referido / cross | Hombro, cefalea, ATM |
| Sistémico / RF | Infección, fractura, malignidad, vascular, inflamatorio |

**AI rule:** Red flags/mielopatía primero. Si cluster radicular (Wainner) coherente → no inundar con MTrP. Miofascial solo con dolor familiar + etiqueta tradicional.

## 2. DOLOR DE HOMBRO

| Tipo | Fuentes posibles |
|------|------------------|
| Tendón / RCRSP | Manguito, bíceps, bursal (constructo) |
| Articular | GH inestabilidad, OA, AC |
| Neural / referido | Cervical (raíz / somático) |
| Miofascial | Infraespinoso, supra, pectoral, elevador |
| Sistémico / RF | Visceral/cardíaco referido, infección, tumor |

**AI rule:** Priorizar RCRSP + cervical según historia (piloto lateral). Miofascial = débil/tradicional. Ver [`../evidence/referred-pain-shoulder-lateral.md`](../evidence/referred-pain-shoulder-lateral.md).

## 3. DOLOR LUMBAR

| Tipo | Fuentes posibles |
|------|------------------|
| Discógeno / neural | Radiculopatía, estenosis |
| Articular | Facetas, SIJ |
| Miofascial | Erectores, QL, psoas |
| Referido distal | Glúteo, ingle, pierna (somático) |
| Sistémico / RF | Cauda, infección, fractura, malignidad, visceral |

**AI rule:** Cauda/RF primero. Cluster neural coherente → claridad. SIJ/cadera si patrón glúteo/ingle. MTrP no primero.

## 4. CADERA / INGLE / GLÚTEO

| Tipo | Fuentes posibles |
|------|------------------|
| Articular | OA, FAI-like |
| Tendón | Glúteo medio/menor, aductores, proximal hamstring |
| Neural / lumbar | Raíz, deep gluteal (cautela) |
| Miofascial | Glúteos, piriforme, TFL, psoas |
| Sistémico | Hernia, visceral, inflamatorio |

**AI rule:** Doha para ingle; lumbar siempre en diferencial de glúteo. Evitar «piriforme» automático.

## 5. RODILLA

| Tipo | Fuentes posibles |
|------|------------------|
| PF / tendón | PFP, rotuliano, cuadricipital |
| Intraarticular | Menisco, LCA/LCM, cartílago |
| Referido | Cadera, lumbar |
| Miofascial / ITB | Cuádriceps, isquios, TFL/ITB |
| Sistémico | Inflamatorio, infección, TVP (poplíteo) |

**AI rule:** Mecanismo local → locales. Local flojo → cadera + lumbar. Tests aislados no excluyen (Hegedus cualitativo).

## 6. TOBILLO / PIE

| Tipo | Fuentes posibles |

## 8. MUÑECA / MANO

| Tipo | Fuentes posibles |
|------|------------------|
| Óseo-ligamentoso | Escafoides, TFCC, DRUJ, carpo |
| Tendón | De Quervain, ECU, flexores |
| Neural | CTS, Guyon, cubital |
| Referido | Cervical, codo |
| Miofascial | Intrínsecos, antebrazo |

**AI rule:** Trauma → protocolo óseo. Parestesias → neural ± cervical. Miofascial no explica déficit sensitivo claro.

## 9. PELVIS / SACRO / SI

| Tipo | Fuentes posibles |
|------|------------------|
| SIJ | Dolor glúteo/sacro con cluster |
| Lumbar | Discógeno, faceta, raíz |
| Cadera | Articular, tendón |
| Suelo pélvico / visceral | Según contexto (derivación) |
| Miofascial | Glúteos, QL, piriforme |
| RF | Fractura sacral, infección, embarazo-complicación |

**AI rule:** No diagnosticar SIJ por un solo test. Diferencial lumbar/cadera obligatorio. Visceral/RF según historia.

## 10. DOLOR TORÁCICO / INTERESCAPULAR

| Tipo | Fuentes posibles (filtrar) |
|------|----------------------------|
| Visceral / RF | Cardíaco, pulmonar, aórtico, TEP, herpes zóster |
| Cervicotorácico | Faceta/segmento C/T, radiculopatía |
| Costilla / pared | Costovertebral, costocondral |
| Hombro | RCRSP, AC (dolor percibido posterior) |
| Miofascial | Romboides, trapecio medio (tradicional = D) |

**AI rule:** Seguridad visceral **siempre primero**. Luego cervicotorácico/hombro. Miofascial solo con dolor familiar y etiqueta D. Ver [`../evidence/referred-pain-thoracic.md`](../evidence/referred-pain-thoracic.md).
