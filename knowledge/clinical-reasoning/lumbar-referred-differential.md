## 1. ESCENARIO

Dolor **lumbar**, **glúteo**, **muslo** o **pierna** donde el clínico duda, SLR/Kemp son negativos, cadera reproduce, o no hay imagen.

**No responder:** «Es el glúteo medio / piriforme.»  
**Sí:** reordenar hipótesis con evidencia etiquetada y exploración discriminativa.

---

## 2. HIPÓTESIS A CONSIDERAR (priorizar)

| Prioridad típica | Hipótesis | Cuándo subir |
|------------------|-----------|--------------|
| 0 | Red flags | Cauda, déficit progresivo, infección/malignidad/fractura, inflamatorio SpA |
| 1 | Radiculopatía / neural | Pierna dominante + neuro; SLR/cruzado + cluster (SLR− no excluye) |
| 2 | Somático referido / faceta experimental | Glúteo/muslo sin neuro duro; mapas McCall/Fukui ≠ nivel en consulta |
| 3 | Hip–spine / cadera | Sentadilla/rotación cadera; FADIR/FABER con dolor familiar |
| 4 | Estenosis / claudicación neurógena | Marcha limitada, alivio en flexión (vs vascular) |
| 5 | SIJ (limitado) | Glúteo; cluster de provocación — nunca un solo test |
| 6 | Miofascial (glúteo) | Solo D/tradicional + dolor familiar |

**Coexistencia permitida:** lumbar + cadera.

---

## 3. PRUEBAS NEGATIVAS

- SLR − → **no** excluye radiculopatía.  
- Kemp − → **no** excluye LBP mecánica / «faceta».  
- Exigir **dolor/síntoma familiar**.

---

## 4. FLUJO

```
Red flags (cauda / infección / fractura / inflamatorio)
→ Neuro + SLR/cluster
→ Si glúteo/ingle: cribado cadera (hip–spine)
→ Estenosis vs vascular si claudicación
→ SIJ solo como hipótesis limitada
→ Miofascial solo D + familiar pain
→ HIPÓTESIS PRINCIPAL / ALTERNATIVA / NO PRIORITARIO
→ Si no mejora: reevaluación (no otro músculo del atlas)
```

## AI RULE

En duda lumbar/glúteo/pierna: seguridad primero; cluster > un test; negativos no excluyen; cadera coexistente; miofascial al final con etiqueta tradicional. Fuente: pack relations `lumbar` v2.
