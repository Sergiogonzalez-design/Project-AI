## 1. ESCENARIO

Dolor de **cuello**, **escápula**, **hombro/brazo** o **cefalea** donde el clínico duda, los tests locales de hombro no reproducen, Spurling/ULTT son negativos, o no hay imagen.

**No responder:** «Es el trapecio / elevador.»  
**Sí:** reordenar hipótesis con evidencia etiquetada y exploración discriminativa.

---

## 2. HIPÓTESIS A CONSIDERAR (priorizar)

| Prioridad típica | Hipótesis | Cuándo subir |
|------------------|-----------|--------------|
| 0 | Red flags | SNOOP, mielopatía, trauma/Canadian C-Spine |
| 1 | Radiculopatía / neural | Cluster Wainner + neuro; brazo/parestesias |
| 2 | Somático / facetario (experimental maps) | Cuello cambia escápula/hombro; no dermatoma claro |
| 3 | Coexistencia RCRSP | Overhead + cuello |
| 4 | Cervicogénica (patrón) | Cefalea + cuello tras SNOOP |
| 5 | Torácico / cervicotorácico | Interescapular; cribado visceral si toca |
| 6 | Entrapment periférico | Mano/codo con cluster cervical flojo |
| 7 | Miofascial (trapecio/elevador) | Solo D/tradicional + dolor familiar |

---

## 3. PRUEBAS NEGATIVAS

- Spurling − → **no** excluye radiculopatía.  
- ULTT − → **no** excluye contribución neural.  
- Exigir **dolor/síntoma familiar**.

---

## 4. FLUJO

```
Red flags (SNOOP / mielopatía / trauma)
→ Cluster cervical + neuro
→ Si hombro/escápula: local cuff vs cervical (coexistencia OK)
→ Cefalea: patrón cervicogénico solo tras SNOOP
→ Miofascial solo D + familiar pain
→ HIPÓTESIS PRINCIPAL / ALTERNATIVA / NO PRIORITARIO
→ Si no mejora: reevaluación (no otro músculo del atlas)
```
