# PHYSIOGUIDE — CLUSTERS TORÁCICO / PARED TORÁCICA

**Capa:** Fase 3 evidence DB  
**Regla:** un cluster es un **patrón de compatibilidad**. No inventar Sn/Sp combinados. Sin CPG TSP específica (Briganti 2023).

---

## CLUSTER A — DOLOR TORÁCICO MECÁNICO NO ESPECÍFICO (Tier C)

**Componentes:**

1. Localización interescapular / paravertebral T  
2. Reproducción con AROM T o carga postural  
3. Red flags visceral/fractura **no** dominantes  
4. Cuello/hombro no explican todo el cuadro  

**AI rule:** «Compatible con TSP mecánico no específico.»  
**Citation:** Briganti 2023; Bogduk/GGC MSK synthesis (inespecificidad estructural frecuente).

---

## CLUSTER B — CONTRIBUCIÓN CERVICOTORÁCICA (Tier B/C)

**Componentes:**

1. Dolor interescapular / escápula medial  
2. El cuello modifica el síntoma familiar  
3. ± hallazgos cervicales (AROM / cluster Wainner si brazo)  

**AI rule:** «Compatible con contribución cervicotorácica.»  
**Citation:** referred-pain-thoracic.md; Dwyer/Bogduk; JOSPT Neck CPG.

---

## CLUSTER C — PARED TORÁCICA MSK / COSTAL (Tier C; post-seguridad)

**Componentes:**

1. Dolor de pared / flanco / costocondral  
2. Respiración/tos/palpación local familiar  
3. Cribado cardíaco/pulmonar favorable o ya descartado médicamente  

**Treatment note (OPTIMa 2015):** multimodal care vs education — mean pain similar; más pacientes reportan mejora importante con multimodal (evidencia limitada).  
**AI rule:** «Compatible con dolor de pared torácica MSK.»  
**Citation:** Southerst et al. *JMPT* 2015 PMID 26141077.

---

## CLUSTER D — FRACTURA / FRAGILIDAD (seguridad — no MSK libre)

Osteoporosis/corticoides/trauma mínimo + dolor óseo → imagen/médico.  
**Citation:** Griffith / ABQ VF literature.

---

## LO QUE NO ES CLUSTER VALIDADO

- «T4 syndrome»  
- «Faceta T confirmada» por palpación  
- «Costilla fuera»  

Etiquetar como evidencia limitada / no usar como diagnóstico.
